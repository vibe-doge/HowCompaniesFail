# 公司败局 · 分析长文写作

## 这个 skill 是什么

把一家公司的失败，写成一篇**有人能从头读到尾、读完能带走一个判断方法**的文章。

它不产出卡片，不出图，不排标签。那些是 `company-failure-cards` 的活。这个 skill 只解决一件事：**怎么把一堆事实写成一篇有思想深度的分析**。

**两套产出的关系**：同一批事实，两种交付。卡片是让人三秒看懂并转发，文章是让人十分钟读进去并记住一个概念。不要混：文章里不该出现「第 1 张」「第一行（白字·光环）」这种生产语言。

## 账号底线（先看这条，再动笔）

**三条禁令**，破了任何一条，这篇就不该写：

1. **不写成功案例**。判断某公司做对了什么，一律不收。
2. **不写推测**。所有数据、人名、时间、金额必须来自法院文书、官方通报或权威公开报道。不编造，不夸大。
3. **不卖课、不接软文、不推代账 / 加盟 / FA**。

**哲学内核**（写「为什么」这一节时的判断标准）：

- **反者道之动**：想成功，先看清失败长什么样。用排除法看商业。
- **含错必错，不含对必错**：生意里含着一个致命错误早晚会死；缺了关键的正确要素也活不下去。
- **成功要天时地利人和加运气，少一个都不行。失败往往只需要一个致命错误。**

## 成品长什么样：七个固定小节

顺序不能变，一节都不能省。**「这套判断能用在哪儿」是长文和新闻稿的分界线，省了它，文章就退化成了加长版新闻。**

```markdown
# 标题（≤20 字，含光环与结局的数字反差）

开头两段：第一段摆光环 + 结局 + 巅峰数字。第二段说出大家最容易想到的读法，
以及它回答不了什么，最后一句交代这篇要拆的是什么。

## 这门生意是怎么赚钱的
## 事情是怎么发生的
## 为什么会走到这一步
## 这套判断能用在哪儿
## 避坑清单
## 免责声明
## 来源
```

### 每节要完成什么

**开头**。第一段就是数字反差，不要铺垫背景，不要写「随着某行业的兴起」。第二段先替读者说出他心里那个读法（「技术太超前，市场没准备好」），再指出它解释不了什么。这一步很关键：**先接住读者的成见，他才愿意跟你往下走**。

**这门生意是怎么赚钱的**。公司做什么、什么时候成立、行业术语当场解释一句。然后交代**两套节奏**：钱从谁那里来、多久来一次；钱往哪里走、多久走一次。这两套节奏对不上，就是后面所有死因的根。光环（创始人履历、融资轮次、巅峰估值）放在这一节末尾。

**事情是怎么发生的**。时间、法院、案号、**谁申请的**。债主申请和创始人自己申请，含义完全不同，这一处最容易被略过，也最有信息量。清算或查封时账上还剩什么，欠了多少。结尾把数字反差再点一次。

**为什么会走到这一步**。全篇重心，三到四条，每条先用一句话点出来（加粗），再展开。**写机制，不写清单**（下面单说）。最后一段是第二层思考。

**这套判断能用在哪儿**。三件事，缺一不可：
① 同一个赛道里有人活下来了，差别在哪（这一步回答开头提出的那个问题）；
② 边界条件：这套判断哪类行业不适用；
③ 给读者一句能带走、能用在下一家公司身上的**判断句**。写清看什么、怎么分，是陈述句：

> 判断一家还没有收入的公司，看它的下一笔钱从哪里来。从客户那里来的，是生意；
> 从一个还没到来的市场那里来的，是期货。

不是反问读者（「它下一笔钱是从客户那里来，还是从一个还没到来的市场那里来？」），
也不写「给读者一句能拿去问任何公司的话」这种替读者安排动作的元叙述。

**避坑清单**。5 条，针对这个行业，不要万能句。**到此结束，不写互动提问。**

**免责声明 + 来源**。见「合规与核实」。

## 深度从哪来：七个动作

这是这个 skill 的核心。**深度不来自词汇的昂贵，来自因果链的完整。**商学院那套案例分析方法能借的是这几手：

| 动作 | 怎么做 | 为什么有效 |
|---|---|---|
| **从异常事实进场** | 开头直接是「90 亿到 90 万」，不是「某公司成立于 2013 年」 | 读者为反常停留，不为背景停留 |
| **给一类公司起个名字** | 「里程碑生意」「信号资本」 | 读者带走的是能复用的框，不是一条八卦 |
| **回答「什么导致什么、为什么」** | 不罗列「它做错了三件事」，交代 A 导致 B、B 导致 C | 因果链能被迁移到别的公司，清单不能 |
| **把这家公司当成一类公司的样本** | 「它不是特例，这一类公司的共同点是……」 | 单个案例是故事，一类案例是知识 |
| **先说出最流行的解释，再拆掉它** | 「靠创始人光环一路融到上市的公司并不少。这个反例成立，但要看清它成立在什么条件上」 | 拆掉一个错的解释，比建立一个对的解释更有说服力 |
| **交代边界条件** | 明说哪类行业不适用这套判断 | 不划边界的结论就是万能金句，而万能金句等于没说 |
| **结尾给判断，不给人生道理** | 「从客户那里来的，是生意；从一个还没到来的市场那里来的，是期货」 | 把分界线说清的陈述句，读者能自己拿去用；道理他只会在心里点个头 |

### 「写机制，不写清单」的具体做法

拿「投资退潮、商业化难、烧钱快」这三条去讲任何一家自动驾驶公司都成立。**换家公司名还读得通的段落，就是没写到这家公司的机制上，重写。**

做法是追一问：**这一条，是这次事件之前就存在的吗？** 事件之后才出现的是后果，事件之前的才是根因。

追到根上之后，把它写成一条链。例如：

> 收入一年来一次，支出天天在走 → 缺口只能靠账上垫着 → 那笔钱从融资来，不从客户来 → 所以公司真正经营的不是技术，是资本对这个赛道的注意力 → 而注意力不随这家公司技术进步增长，随「别人也在投」增长 → 第一笔钱好拿，因为买的是故事；第五笔钱难拿，因为要看到故事之外的东西。

这条链每一环都能被别家公司复用，但它指向的是这一家的具体处境。

### 第二层思考怎么写

别人看到的是什么，往下再看一层是什么。**直接写那层看到的东西，不要写「这里要有第二层思考」**（这句话曾经被照字面写进过正文，是站上真实出过的事故）。

好的第二层是把「公司」和「项目」、「信号」和「能力」、「桥」和「家」这种平时混在一起的东西分开：

> 别人看到的是「又一家自动驾驶公司倒了」。往下再看一层：它做的更接近一个项目而不是一家公司。项目只需要技术成立，公司需要一条自己能闭合的现金流。

## 写作规则

**语气**：简体中文，冷峻、客观、口语化、一针见血。

**禁止用的词**：「单位经济模型」「边际效益」「战略失焦」「第一 / 第二 / 第三」「极其致命」。改用「第一个死穴」「这步棋走得太臭了」「两头堵死」。

**格式禁令**：

- 不用感叹号，不说教，不写段尾升华句。
- **正文里一个问号都不留**。腔调向澎湃新闻的思想 / 时政版靠：全篇陈述句，读者的疑问由作者替他说出来再回答掉，不由作者抛回去。这条**包括第三人称的反问式判断句**（「它下一笔钱是从客户那里来，还是从一个还没到来的市场那里来？」）——看着像深度装置，其实就是把活儿推给读者。
- **不写引导互动的话术**。「你身边有这样的朋友吗」「你在的行业呢」「评论区聊聊」这类，是小红书的互动权重玩法。**文章是给读者一个人读的**，向读者发问没人接得住，删掉。同理不写「你可能会说」这种第二人称引导，直接把流行解释说出来再拆掉。
- 正文里不用破折号，改用冒号或逗号。
- 金额不加千分位逗号（写「90.38 万元」，不写「903,800 元」）。
- **禁止万能金句**（「技术再牛，没人买单就是自嗨」这种）。判据：这句话放在任何一家公司身上都能用吗？能，就删掉重写。

**必须做到的**：

- **扒具体细节**。新闻里最有戏剧性的那一处要写进去，比如听证会上的原话、法院文书里的具体金额。抽象的判断是分析，具体的细节才是内容。
- **术语当场解释**。读者不懂这行也要读得下去：「L4 级的意思是，车在划定的区域里完全自己开，方向盘后面不用坐人。」

## 去 AI 味

对照 `humanizer-zh` 的清单（源自维基百科 Signs of AI writing）。这个账号实际犯过、要重点查的：

| 别写 | 改成 |
|---|---|
| **元叙述**：「这里要有第二层思考。」 | 直接写那层看到了什么 |
| **段尾升华句**：「技术理想与商业现实的鸿沟，最后没能跨过去。」 | 删 |
| **假深度**：把话说得比证据大（「这标志着一个时代的终结」） | 说清证据支持到哪一步 |
| **断句造势**：「最扎眼的数字是 1.5 万。不是 1.5 亿。」 | 合成一句：「最扎眼的数字是 1.5 万，不是 1.5 亿。」 |
| **自指**：「这条不是劝退」 | 去掉「这条」 |
| **空转加强词**：「值得注意的是」「本质上」「真正的信号是」 | 删 |
| **「不是……而是……」连用** | 一段里最多一次，其余改写 |

**长文特有的 AI 味是「假深度」**：连续三段一个句式、每段结尾都补一句总结、把结论说得比证据大。写完自查：**把每一段的最后一句单独抽出来排在一起读，像不像在念排比句。**

避坑清单那 5 条**不适用**「删除金句」这条规则，它们按格式就该是可截图收藏的短句。

## 合规与核实

- **关键争议点用官方定性表述**。创始人「失联」必须依据官方通报，不能写成「被抓」或「逃往海外」。
- **有法律风险的说法用原始信源的原话撑着**。
- **免责声明逐字照抄，一个字不改**，里面**绝不出现任何具体媒体名称**（界面新闻、澎湃、36氪这类一律不写），统一写「综合公开报道及法院公开文书」：

  > 案例信息综合自公开报道及法院公开文书，仅作商业案例分析，不构成任何创业或投资建议。本账号已尽力核实信息，但不排除报道更新或细节偏差，读者请自行查证。

- **来源栏逐条列出处**，能查到案号就写案号。找不到独立出处的数字，**在来源栏明写「出自本账号原帖，暂未找到独立可查的原始出处」**，不要默默用掉。
- **属于分析而非事实的段落要标出来**。比如「收入结构和支出节奏」是对整个赛道的归纳，不是这家公司披露的财务数据，来源栏里要说明。**读者能分清哪些是事实、哪些是判断，这个号才立得住。**

## 工作流

1. **核事实**。先拿到案号 / 判决 / 权威报道。没有出处的公司不做。
2. **找那两套节奏**。这家公司的钱从谁那里来、多久一次；往哪里走、多久一次。找不到就先别写「为什么」那节。
3. **追根因**。对每条候选死因问「这一条是这次事件之前就存在的吗」。留下事件之前就存在的。
4. **连成链**。把根因按 A 导致 B、B 导致 C 排，不是并列罗列。
5. **想边界**。这套判断哪类行业不适用？同赛道活下来的那家差别在哪？
6. **写判断句**。一句读者能带走、能用在下一家公司身上的话。是陈述句，不是反问。
7. **落草稿**，按七节填。
8. **自检**（下一节），过了再发。

## 发布前自检

逐条过，有一条不过就改：

- [ ] 换掉公司名，文章还读得通吗？读得通，说明没写到机制上。
- [ ] 「这套判断能用在哪儿」这节在不在？边界条件写没写？
- [ ] 正文里有没有「第 N 张」「第一行（白字·光环）」这类生产语言？
- [ ] 正文里还有没有问号？（一个都不该有，包括看似是深度装置的反问句）
- [ ] 有没有「你身边……吗」「你在的行业呢」「评论区聊」这类引导互动的话术？有没有「你可能会说」这类第二人称引导？
- [ ] 每一段的最后一句抽出来排一起，像不像排比句？
- [ ] 免责声明是否逐字等于模板，里面有没有媒体名？
- [ ] 每个数字在来源栏里都有出处？找不到出处的有没有明写？
- [ ] 有没有哪句话放在任何公司身上都能用？有就删。
- [ ] 有没有感叹号、破折号、千分位逗号？
- [ ] 「不是……而是……」在一段里出现了几次？

## 在本仓库里工作时

这个 skill 是通用方法。落到 `HowCompaniesFail` 这个仓库，还有一层仓库自己的规矩：

- **字段和格式以仓库根的 `CLAUDE.md` 为准**（frontmatter 七字段、七节顺序、免责声明模板）。
- **写完跑 `node tools/check-frontmatter.mjs`**，它会校验字段、节序、免责声明逐字、避坑清单 5 条，并拦住正文里的「第 N 张」。
- 新条目追加在 `docs/entries/` 末尾，文件名 `NNN-公司名.md`。
- 封面文案、标签、发布后首评、评论区回复**不进这个仓库**，在 `company-failure-cards` 那边维护。
