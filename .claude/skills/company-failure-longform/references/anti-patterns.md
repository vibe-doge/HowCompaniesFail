# AI 味与结构病的改写对照

下面每一条都是**这个号真实出过的**，不是编的例子。

## 元叙述：把规则照字面写进正文

规则写着「必须加入第二层思考」，结果两条 entry 的正文里各躺着一句：

```text
这里要有第二层思考。别人看到的是「又一家自动驾驶公司倒了」。
真正的信号是：这类公司从成立第一天起，收入就不是它的氧气，融资才是。
```

**病在哪**：报幕。读者要看的是那层思考，不是「我要开始思考了」的预告。
另外「真正的信号是」也是空转加强词。

```text
别人看到的是「又一家自动驾驶公司倒了」。往下再看一层：
这类公司从成立第一天起，收入就不是它的氧气，融资才是。融资一断，
技术再先进也只能停在原地。
```

**改法**：删掉报幕句，直接从「别人看到的是」接下去。
「往下再看一层」是过渡，不是宣告。

**教训**：写规则的时候要想到它会被人（或模型）照字面执行。
「必须加入第二层思考」这种写法太容易被读成「写上这句话」。

## 段尾升华句

```text
技术理想与商业现实的鸿沟，最后没能跨过去。
```

**病在哪**：删掉它，这一段的信息一点不少。它唯一的作用是制造一个「收束感」，
而收束感是 AI 写作最典型的指纹。**全文的段尾句要逐句查。**

```text
（直接删，上一句说完就结束）
```

**判据**：段尾句如果是在下结论、定主次、说该怎么做，留下意思；
如果只是把前文换个说法再说一遍，或者往上抬一层情绪，删。

## 断句造势

```text
最扎眼的数字是 1.5 万。不是 1.5 亿。
```

**病在哪**：把一个对比拆成两句，用句号制造停顿感。这是短视频脚本的习惯，
落到文字上就是装。

```text
最扎眼的数字是 1.5 万，不是 1.5 亿。
```

**改法**：合成一句，用逗号。同样的信息，语气平实得多。

## 自指

```text
这条不是劝退。
```

```text
不算劝退。
```

**改法**：去掉「这条」「本条」。但**限定本身要留下**：「不算劝退」这个限定
是内容，不是包装。删自指，不删意思。

## 空转加强词

- 「值得注意的是」
- 「本质上」
- 「真正的信号是」
- 「究其原因」

**全部删**。这些词不承载信息，只制造「我在深入分析」的错觉。

## 假深度：长文特有的病

短卡片不容易犯，长文很容易。

```text
这标志着一个自动驾驶时代的终结。
```

**病在哪**：把话说得比证据大。手上有的是「一家公司破产清算」这一个事实，
推不出「一个时代终结」。

```text
同一批公司里，转做量产供应商的活下来了，死磕 L4 的排队等钱。
```

**改法**：只说到证据支持的那一步。

**自查法**：把每一段的最后一句单独抽出来排在一起读。
如果像在念排比句（句式雷同、一句比一句高），就是假深度。

## 结构病：把清单当分析

```text
死穴一：自动驾驶投资退潮，融资环境收紧，后续的钱跟不上。
死穴二：L4 级技术商业化落地困难，短期内做不出正向现金流。
死穴三：烧钱速度远超营收，一直靠融资输血维持。
```

**病在哪**：这三条放到**任何一家**自动驾驶公司身上都成立。
它不是分析，是新闻摘要。

**改法**：追因果链，不列并列项。

```text
收入一年来一次，支出天天在走 → 缺口只能靠账上垫着 → 那笔钱从融资来，
不从客户来 → 所以公司真正经营的不是技术，是资本对这个赛道的注意力 →
而注意力不随这家公司技术进步增长，随「别人也在投」增长。
```

**判据**：换掉公司名，文章还读得通吗？读得通，就是没写到机制上。

## 结构病：提了问题不回答

开头写了「同一批做自动驾驶的公司里，有人活到了今天」，
然后全篇再没提这件事。

**读者会记着这个坑。** 开头提出的问题，「这套判断能用在哪儿」那节必须回答。

## 结构病：不划边界

```text
技术型创业者要记住：没有收入的商业模式撑不过融资寒冬。
```

**病在哪**：放在任何公司身上都能用，等于没说。而且它不告诉读者什么时候**不**适用。

**改法**：明说哪类行业是例外，为什么是例外。

## 互动话术（2026-10-07 起禁）

```text
你身边有做自动驾驶创业的朋友吗？
```

```text
你在的行业，钱是跟着技术走，还是跟着收入走？如果明天融资停了，你还能发几个月工资？
```

**病在哪**：这是小红书的互动权重玩法，评论能推流量。但**站点是纯前端，
没有评论区**，向读者发问没人接得住，读者读到这儿只会觉得莫名其妙。

**改法**：删掉，避坑清单说完第 5 条就结束。

## 反问式的判断句（2026-10-07 同日追加禁）

第一轮只删了第二人称那类，留下了第三人称的反问，理由是「它是深度装置不是互动装置」。
用户的反馈是这条界线不成立：

> 问用户的，互动的删掉，文章很少带这个。要像澎湃新闻思想时政那样，有深度。
> 有思想深度，因此不需要引导评论。这是网页。

```text
给读者一句能拿去问任何公司的话：**它下一笔钱，是从客户那里来，
还是从一个还没到来的市场那里来？** 如果是后者，接着问第二轮：
那个市场到来的时间，是谁定的，写在哪份文件上。答不上来，
那买的就不是这家公司，是那个未来。
```

**两处病**：

- **元叙述**。「给读者一句能拿去问任何公司的话」是在替读者安排他的动作，
  读者要看的是那句话本身，不是「我接下来要给你一句话」的预告。
- **反问**。带个问号看着像留白，其实是把活儿推回给读者。澎湃那一路的
  思想 / 时政文章全篇陈述句，疑问由作者替读者提出来、再回答掉。

```text
判断一家还没有收入的公司，看它的下一笔钱从哪里来。**从客户那里来的，
是生意；从一个还没到来的市场那里来的，是期货。**接着要看的是那个市场
到来的时间由谁定、写在哪份文件上。答不上来，买的就不是这家公司，是那个未来。
```

**改法**：把分界线直接说出来。判断句之所以能带走，靠的是它说清了「怎么分」，
不是靠它带个问号。**判据：正文里一个问号都不该有**，
`tools/check-frontmatter.mjs` 会拦。

**同理还有第二人称的引导语**：「你可能会说，不少公司确实是靠创始人光环一路融到
上市的」改成「反例是有的。靠创始人光环一路融到上市的公司并不少」——
直接把流行解释说出来，再拆掉它，不用先跟读者打招呼。
