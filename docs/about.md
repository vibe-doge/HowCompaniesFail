# 收录标准与立场

## 这本书收录什么

**只收已经有人踩过的坑。**

- 收：有判决书、行政处罚决定书、官方通报、年报可查的失败案例。
- 不收：成功案例。成功不可复制，失败可以避免。
- 不收：推测的因果。「大概是因为资金链断了」这种话不写，除非有出处。

## 证据分级

| 等级 | 判据 |
|---|---|
| **A** | 有判决书或行政处罚决定书，**能查到案号** |
| **B** | 有官方统计、年鉴、监管问答或典型案例通报，但对不上具体个案 |
| **C** | 行业内普遍说法，没有官方出处，会写明凭什么这么判断 |

A 级是这本书的命根子：能截图、能核对、转发的人不担责。

## 来源规则

只引判决书、行政处罚决定书、官方通报、年报、统计年鉴、部委文件。

一手媒体报道（记者署名的原创调查或现场报道）只在没有官方文书时收，而且会明确标注「此案只有媒体报道，没有判决或官方通报」，附网页存档链接。数字不从报道里取。

不引知乎、微信公众号、搜狐、网易、百家号，以及任何二手汇编。

## 立场

这个仓库**不卖课、不接软文、不推代账 / 加盟 / FA**。

读者是来避坑的，而这几类往往就是坑本身。

## 关于写到的公司和个人

- 只写判决书、处罚决定书、官方通报里已经认定的事实。
- 没被判决的个人不写全名，涉事公司可以写。
- 如果某条内容与事实有出入，欢迎提 issue 并附出处，核实后改。

## 免责

这里给的是通用情况，不构成法律意见。具体案子请找执业律师。
