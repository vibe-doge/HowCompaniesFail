# 收录标准与立场

## 为什么从失败看起

失败乃成功之母这句老话，反过来读更实在：成功没法复制。一次成功是天时、地利、人和、贵人，再加上个人努力，一层层叠出来的，少一层都不成立。讲成功的人很少提当时的客观条件和政策，也很少讲中间绕了多大的弯，这些外人本来就看不见，所以照着成功者的方法做一遍，大概率也成不了。

失败可以复制，而且经常只需要一个致命错误。

这就是反者道之动：想成功，先看清失败长什么样，用排除法看商业。生意里含着一个致命错误，早晚会死；缺了关键的正确要素，也活不下去。含错必错，不含对必错。

这里只解剖失败，不谈成功。

## 这个站收录什么

只收已经有人踩过的坑：

- 收：有法院文书、官方通报或权威公开报道可查的失败案例。
- 不收：成功案例。成功是偶然的，失败是常态。避开坑，比模仿成功更重要。
- 不收：推测。所有数据、人名、时间、金额都要有出处，不编造、不夸大。

## 一条案例里有什么

一条案例就是一篇文章：

| 节 | 内容 |
|---|---|
| 开头 | 光环、结局、巅峰估值，在一段里摆出数字反差 |
| 这家公司是做什么的 | 公司做什么、什么时候成立。行业术语当场解释一句 |
| 事情是怎么发生的 | 时间、法院、案号、谁申请的，清算时账上还剩什么 |
| 为什么会走到这一步 | 3 到 4 个根本死因，大白话，每个先用一句话点出来 |
| 避坑清单 | 5 条针对这个行业的教训，不要万能句 |
| 免责声明 | 固定模板，每一条都一样 |
| 来源 | 用来自己核对的出处 |

**站点上只放文字**，不做图片还原，也不存生图提示词。封面文案、标签、发布后自己评论那一条，属于发布环节，不在这个站上。

## 来源分两档

| 档 | 判据 |
|---|---|
| **法院文书** | 有案号，能在中国裁判文书网或全国企业破产重整案件信息网查到 |
| **公开报道** | 只有公开报道，没有查到案号、判决书或官方通报。这一类会在来源栏里写明，读者引用前请自行核实 |

两档只差这一点。**公开报道那一档，数字照样要有出处，不从报道里凭印象取。**

## 事实核查

- 关键争议点用官方定性表述。比如创始人「失联」必须依据官方通报，不能写成「被抓」或「逃往海外」。
- 某个说法有法律风险时，正文里用原始信源的原话撑着。
- 免责声明里不出现任何具体媒体名称，统一写「综合公开报道及法院公开文书」。

## 立场

不卖课，不接软文，不推代账、加盟、FA。这几类本身就是坑，这个号拆的就是它们。

## 关于写到的公司和个人

- 只写法院文书、官方通报、公开报道里已经认定的事实。
- 没被判决的个人不写全名，涉事公司可以写。
- 如果某条内容与事实有出入，欢迎提 issue 并附出处，核实后改。

## 免责

这里给的是商业案例分析，不构成任何创业或投资建议。具体的事请找执业律师。
