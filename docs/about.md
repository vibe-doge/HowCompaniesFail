# 收录标准与立场

## 为什么从失败看起

老话说失败乃成功之母。但真正的问题是：**成功不可复制。**

任何一次成功，都是天时、地利、人和、贵人，再加上个人努力，一层层叠加出来的，少一层都不成立。那些讲成功的人，很少提客观条件和政策，也很少讲中间绕了多大的弯——我们无从得知。所以照着成功者的方法执行，大概率也成功不了。

反过来，失败是可以复制的，而且经常只需要一个致命错误。

这就是**反者道之动**：想成功，先看清失败长什么样。用排除法看商业——**含错必错，不含对必错**：生意里含着一个致命错误，早晚会死；缺了关键的正确要素，也活不下去。

所以这里只解剖失败，不谈成功。

## 这个站收录什么

**只收已经有人踩过的坑。**

- 收：有法院文书、官方通报或权威公开报道可查的失败案例。
- 不收：成功案例。成功是偶然的，失败是常态。避开坑，比模仿成功更重要。
- 不收：推测。所有数据、人名、时间、金额都要有出处，不编造、不夸大。

## 一条案例里有什么

一条案例就是一个完整的图文发布包，按小红书那边的顺序排：

| 段 | 内容 |
|---|---|
| 第 1 张 | 封面。第一行白字写光环，第二行红字写惨烈结局，左下角「公司败局 公司名」 |
| 第 2 张 | 发生了什么。分行罗列事实 |
| 第 3 张 | 为什么会走到这一步。3 到 4 个核心死因，大白话 |
| 第 4 张 | 避坑清单。5 条可截图收藏的行业专属金句 |
| 第 5 张 | 一句话总结 |
| 正文 | 光环背景、高光与陨落、为什么走到这一步、避坑清单、金句总结、互动提问 |
| 免责声明 | 固定模板，每一条都一样 |
| 标签 | 5 到 8 个 |
| 互动 | 发布后自己评论一条，以及评论区回复参考 |
| 来源 | 站点比小红书多出来的一段，用来核对 |

站点上**只放文字**，不做图片还原，也不存生图提示词。

## 来源分两档

| 档 | 判据 |
|---|---|
| **法院文书** | 有案号，能在中国裁判文书网或全国企业破产重整案件信息网查到 |
| **公开报道** | 只有公开报道，没有查到案号、判决书或官方通报。这一类会在来源栏里写明，读者引用前请自行核实 |

两档只差这一点。**公开报道那一档，数字照样要有出处，不从报道里凭印象取。**

## 事实核查

- 关键争议点用官方定性表述。比如创始人「失联」必须依据官方通报，不能写成「被抓」或「逃往海外」。
- 某个说法有法律风险时，正文里用原始信源的原话撑着。
- 免责声明里不出现任何具体媒体名称，统一写「综合公开报道及法院公开文书」。

## 立场

这个仓库**不卖课、不接软文、不推代账 / 加盟 / FA**。

读者是来避坑的，而这几类往往就是坑本身。

## 关于写到的公司和个人

- 只写法院文书、官方通报、公开报道里已经认定的事实。
- 没被判决的个人不写全名，涉事公司可以写。
- 如果某条内容与事实有出入，欢迎提 issue 并附出处，核实后改。
