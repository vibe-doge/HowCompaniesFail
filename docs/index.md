# 公司败局案例集

每期解剖一家真实倒闭的公司。讲可查证的事实，写能用的避坑清单。

这里不教你怎么创业，只讲别人是怎么死的。收录的每个坑都有人已经掉进去过，每条都带出处，法院文书或公开报道，能自己核对。

为什么从失败看起：成功没法复制。一次成功是天时、地利、人和、贵人，再加上个人努力，一层层叠出来的，少一层都不成立。失败可以复制，而且经常只需要一个致命错误。这就是反者道之动，想成功，先看清失败长什么样。

不写成功学，只写失败学。全部文章列在左边，立场和收录标准在[收录标准与立场](/about)。
