# 公司败局案例集

**每期解剖一家真实倒闭的公司。讲可查证的事实，写能用的避坑清单。**

不写成功学，只写失败学。

## 这是什么

一本**创业错题集**。

这里不教你怎么创业，只讲别人是怎么死的。收录的每个坑都有人已经掉进去过，每条都带出处，法院文书或公开报道，能自己核对。

每条案例都是一个**完整的图文发布包**：五张图的文字、正文、免责声明、标签、发布后自己评论的那一条、评论区回复参考。照抄就能发。

## 站点

**https://vibe-doge.github.io/**

- **错题集**（`/entries/`）—— 按光环、行业、结局三个维度交叉筛选
- **收录标准与立场**（`/about`）—— 来源怎么分档、引什么、不做什么

## 收录标准

- **法院文书**：有案号，能在中国裁判文书网或全国企业破产重整案件信息网查到。
- **公开报道**：只有公开报道，没有案号、判决书或官方通报。这一类会在来源栏写明。

区别只有这一条：公开报道那一档，数字照样要有出处，不从报道里凭印象取。

## 事实核查

- 关键争议点用官方定性表述。比如创始人「失联」必须依据官方通报，不能写成「被抓」或「逃往海外」。
- 免责声明里不出现任何具体媒体名称，统一写「综合公开报道及法院公开文书」。

## 立场

这个仓库不卖课、不接软文、不推代账 / 加盟 / FA。这几类本身就是坑，这个号拆的就是它们。

## 本地跑站点

```bash
npm install
npm run dev        # 本地预览
npm run build      # 构建
npm run check      # 校验条目格式
```

## 加一条新案例

复制 `docs/entries/_模板.md`，改名成 `NNN-公司名.md`，照模板填。

格式规则写在 [CLAUDE.md](CLAUDE.md)，`npm run check` 会校验字段、十段顺序、免责声明是否逐字等于模板、避坑清单是不是正好 5 条。
