# HowCompaniesFail · 公司败局

**每期解剖一家真实倒闭的公司。只讲可查证的事实，只列能用的避坑清单。**

不写成功学，只写失败学。

## 这是什么

一本**创业错题集**。

不是教你「怎么创业」，是告诉你「别人是怎么死的」。收录的每一个坑都有人已经掉进去过，每条都带出处——判决书、行政处罚决定书、官方通报——能自己核对。

每条错题回答两件事：

1. **别人是怎么死的**（有出处的事实，不是推测）
2. **你现在是不是也站在坑边上**（三个自检问题，能对号入座）

## 怎么用

**别通读。** 遇到具体的事再来查——合伙人要撤资、要签对赌、要交加盟保证金、要给员工画股权。

查到一条之后：

1. 先看【自检】那三个问题。一个都不中，说明不是你的事，翻下一条。
2. 中了，看【案例】和【死因】——搞清楚别人是怎么输的。
3. 最后看【重来一次】，那是一个动作，不是一堆道理。

## 收录标准

- **A 级**：有判决书或行政处罚决定书，能查到案号。
- **B 级**：有官方统计、年鉴、监管问答或典型案例通报。
- **C 级**：行业普遍说法，没有官方出处，会写明凭什么这么判断。
